# Dungeon Delver — 3D Pinball

A dungeon-crawler RPG pinball game that runs in the browser, built with Three.js.

**Play:** https://jonbeam1-netizen.github.io/dungeon-delver-pinball/

- Four playfields: the main table, the Dragon's Den upper deck, and two side tables (The Crypt and The Forge), with 8 flippers
- Slay five monsters per floor, collect relics, complete quests, unlock achievements
- Treasure Hoard and Hellfire multiball, wire ramps, rats, rescues, curses and more
- All 3D models, textures, sounds and music are generated in code

Controls: Z / Left Shift / ← and / / Right Shift / → for flippers, Space to plunge, E for hero power, V to change camera.
